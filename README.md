# 🚧 AI Smart Pothole Detection System

## Project Overview

The AI Smart Pothole Detection System is a web-based application developed using **Python, Flask, and OpenCV**. It enables users to upload road images and automatically detects potholes using image processing techniques. The system counts detected potholes, classifies their severity, records GPS coordinates (when available), and stores reports with an interactive map for visualization.

---

## Features

- Upload road images for analysis
- AI-based pothole detection
- Automatic pothole counting
- Severity classification (Low, Medium, High)
- GPS location tracking
- Interactive map visualization
- Report history management
- User-friendly web interface

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/AI-Smart-Pothole-Detection-System.git
```

### 2. Navigate to the project folder

```bash
cd AI-Smart-Pothole-Detection-System
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open your browser

```
http://127.0.0.1:5000
```
